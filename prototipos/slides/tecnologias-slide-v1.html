Cronos
02·Tecnologias
Stack que faz o Cronos funcionar
As 12 ferramentas em uso e o que cada uma resolve.
Python
Base3.11+
Linguagem que conecta tudo. Bibliotecas maduras pra dados, ML e web — sem precisar misturar stacks.
Pandas
Dados2.2
Lê o Excel, filtra incidente-pai (regra de KPI) e monta as features temporais (lag, rolling, is_feriado).
NumPy
Dados2.2
Aritmética vetorizada por trás do Pandas. Transforma milhares de séries temporais em uma fração do tempo.
BR
holidays BR
Dados0.97
Calendário oficial de feriados nacionais. Vira o is_feriado que muda completamente o padrão de volume.
P
Prophet
MLMeta
Prevê volume diário de incidentes (D+1 e D+7). Lida bem com feriados e sazonalidade sem tunagem pesada.
XGB
XGBoost
MLlatest
Classifica risco de OLA por incidente. Robusto em dados tabulares e desbalanceados — o cenário do Cronos.
ts
tslearn
MLlatest
Agrupa padrões com DTW. K-Means clássico falha quando os picos não ocorrem no mesmo horário — DTW resolve.
Sh
SHAP
MLlatest
Mostra o porquê de cada previsão do XGBoost. Sem caixa-preta — toda recomendação é explicável.
Django
App5.x
Backend maduro. ORM, autenticação, admin já vêm prontos. Roda com Postgres ou SQLite sem mexer no código.
Plotly
App6.0
Gráficos interativos do dashboard. Hover, zoom e drilldown sem precisar escrever JavaScript.
Claude API
IASonnet
Escreve o morning brief e os alertas em linguagem natural. Não é chat — roda nos bastidores.
Docker
Deploycompose
Empacota todo o pipeline num docker compose up. Locaweb roda na infra dela, sem amarração de cloud.
